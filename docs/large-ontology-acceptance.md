# 大本体优化验收抽查(go.owl)

> 2026-09-06,P 里程碑收尾时整理;配合 8734 端口手动验收。

1. **三段分层**:导入 go.owl(约 78k 存活类,> 2000)→ 总览自动进入渐进模式:
   根层为少量折叠节点(子树大小徽章)+ 一个「已废弃」桶节点(约 13,894)。
   顶栏「全图」Toggle 强制 `view=full` → 回到旧的 5000 节点截断视图;「渐进」Toggle 强制折叠视图。
2. **就地展开**:点任一折叠根的 `+徽章` → 直接子类落位在父下方一行(已保存布局时不动其他节点);
   再点 `−徽章` → 子树移除。嵌套展开后逐层收起应干净回退。
3. **废弃桶**:点「已废弃」桶 → 前 500 个废弃类平铺(truncated 提示);
   开启「显示已废弃」Toggle 后树/总览直接包含废弃条目。
4. **rdfs:label 优先**:GO_0005575 等类的节点名显示 `cellular_component` 等 label,
   无 label 时回退 curie 局部名(如 `GO_0008150`)。
5. **增量编辑(大本体上)**:任选一类改名/加注释 → 响应毫秒级,读路径立即可见;
   约 3s 后落盘(saveState: pending → idle);meta 的 revision 每次编辑 +1,
   陈旧 revision 提交 → 409 EDIT_CONFLICT。
6. **渐进定位**:渐进模式下全局搜索(Ctrl/⌘K)选中深层类 → 画布重置为该类单节点 + 其折叠子。
