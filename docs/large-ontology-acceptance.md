# 大本体优化验收抽查(go.owl)

> 2026-09-06 P 里程碑收尾时整理;2026-09-07 按当前 UI 修订(「全图」Toggle 与画布
> 废弃桶已移除、展开布局改宽度感知折行、徽标口径改存活)。配合 8734 端口手动验收。

1. **三段分层**:导入 go.owl(约 78k 存活类,> 2000)→ 总览自动进入渐进模式:
   根层为少量折叠节点(徽标数字 = 存活子树大小,无存活后代的根不画徽标)。
   顶栏「渐进」Toggle 强制折叠视图;`view=full` 保留为 API 能力,无 UI 入口。
2. **就地展开**:点任一折叠节点的 `+徽章` → 直接子类落在父节点下方(按真实卡片
   宽度排布,单行超宽折成居中子行;已保存布局时不动其他节点);展开出的子节点带
   自己的角标,可继续逐层下钻(如 GO:0003774 `+11` → 4 个子类)。再点 `−徽章` →
   子树移除,嵌套展开后逐层收起应干净回退。
3. **废弃浏览**:画布永不显示废弃类;左侧栏「类」tab 底部有「已废弃」分组行,
   展开即平铺浏览全部废弃类(虚拟滚动扛 13k+ 行);画布顶部提示条给出隐藏计数
   并指向侧栏。
4. **rdfs:label 优先**:GO_0005575 等类的节点名显示 `cellular_component` 等 label,
   无 label 时回退 curie 局部名(如 `GO_0008150`)。
5. **增量编辑(大本体上)**:任选一类改名/加注释 → 响应毫秒级,读路径立即可见;
   约 3s 后落盘(saveState: pending → idle);meta 的 revision 每次编辑 +1,
   陈旧 revision 提交 → 409 EDIT_CONFLICT。
6. **渐进定位**:渐进模式下全局搜索(Ctrl/⌘K)选中深层类 → 画布重置为该类单节点
   + 其折叠子。
